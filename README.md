This a learning opportunity to explore different mathematical modelling techniques to play
Fantasy Premier League. Different directions to explore would be classical statistics - where we would try to 
model xPoints on different parameters, linear optimisation - calculate optimum values of parameters to maximise total
points, machine learning and regression, modelling using Deep learning techniquest, portfolio management strats, 
and RL. This is a very open ended problem at this moment, will see what strategies we can code up and test.
Eventually we might be in a position to create a hybrid strategy that out-performs each. 

The aim of the project is to create a real world scenario where we learn and explore different ways
of modelling this complex and dynamic system.
